# Harthmere Voice Test Matrix

This matrix covers the selectable ElevenLabs/Azure NPC voice path: microphone capture,
speech-to-text, generated NPC chat, text-to-speech, voice assignment, and
playback. Voice must remain optional; when any required Azure deployment
or ElevenLabs configuration is absent, the game should keep normal text
dialogue working.

| Area                       | Scenario                                                                                                                                                                                                                                          | Guardrail                                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Capability status          | No provider config, Speech-only config, OpenAI-only config, ElevenLabs-only config, and full config                                                                                                                                               | `src/pages/api/voices/test/speech_status.test.ts`                                                                             |
| API schema                 | TTS requires text + voice, STT requires audio, status and voices list response shapes stay stable                                                                                                                                                 | `src/pages/api/voices/test/voice_api_schema.test.ts`                                                                          |
| Browser talk button        | Button requires browser recording APIs, speech-to-text, and generated chat; NPC TTS may be disabled                                                                                                                                               | `src/client/components/system/npcSpeechInputState.test.ts`                                                                    |
| Microphone selection       | Options tab lists browser microphones, keeps browser default first, falls back when a stored mic disappears, and passes the selected device to recording                                                                                          | `src/client/components/biomes_ui/tabs/microphoneDeviceSettings.test.ts`, `src/client/components/system/speechCapture.test.ts` |
| Microphone recording       | WAV header, PCM16 clamping, downsampling, short clips, base64 upload payload                                                                                                                                                                      | `src/client/components/system/speechCapture.test.ts`                                                                          |
| Azure Speech TTS           | Optional config, invalid/legacy voice id, empty text, SSML escaping, endpoint/headers, error surfacing                                                                                                                                            | `src/server/shared/test/azure_speech.test.ts`                                                                                 |
| Azure Speech STT           | Optional config, empty audio, non-WAV rejection, language routing, no-match transcript, error surfacing                                                                                                                                           | `src/server/shared/test/azure_speech.test.ts`                                                                                 |
| Azure voices list          | Voice list endpoint, subscription header, provider failure                                                                                                                                                                                        | `src/server/shared/test/azure_speech.test.ts`                                                                                 |
| ElevenLabs TTS             | Server-only config, natural stability/style/speed policy, punctuation and paragraph normalization, stage-direction suppression, voice discovery pagination, stable presentation matching, request headers/body, and explicit voice-pool overrides | `src/server/shared/test/elevenlabs.test.ts`                                                                                   |
| Azure OpenAI               | Optional config, env aliases, Responses API request shape, output formats, error surfacing                                                                                                                                                        | `src/server/shared/test/azure_openai.test.ts`                                                                                 |
| Generated NPC chat         | Player-name sanitization, raw context sanitization, no repeated openings, missing buttons, markup parsing, empty output rejection, same-NPC context isolation, history limiting                                                                   | `src/pages/api/npcs/test/generated_chat_likeability.test.ts`                                                                  |
| Quest voice context        | Active incomplete NPC quest is prioritized; completed/inactive quests stop affecting the NPC response                                                                                                                                             | `src/client/components/challenges/harthmereVoiceContext.test.ts`                                                              |

| NPC voice casting          | Gender/kind inference, provider-neutral actor metadata, parseable Azure prosody, deterministic ElevenLabs selection, SSML cleanup, legacy fallback                                                                                                | `src/shared/harthmere/test/npc_voice_profiles.test.ts`, `src/server/shared/test/elevenlabs.test.ts`                           |
| Playback                   | Immediate duplicate suppression, TTL expiry, changed provider/voice/language separation, playback id changes do not replay the same line                                                                                                          | `src/client/components/system/VoiceChat.test.ts`                                                                              |
| Rendered conversation flow | Every rendered dialogue scene plays once; hold/release `T` and click recording both work; choices are not bypassed; empty or failed STT does not freeze the UI                                                                                    | `src/client/components/challenges/TalkDialogModalStep.browser.test.tsx`                                                       |
