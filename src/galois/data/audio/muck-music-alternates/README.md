# Muck music versions

All muck-area music versions are intentionally retained.

- `../muck-music-1.webm` is the active 3:48 Harthmere overworld loop. The
  runtime `muck_music` key resolves to this file.
- `muck-music-original-morgan-herrell.webm` is the original 9:52 muck-area
  track by Morgan Herrell.
- `muck-music-elevenlabs-short-loop.webm` is the earlier 1:52 generated loop.

The generated MP3 copies, unlooped masters, prompts, and composition plans are
also retained under `artifacts/music/` in this workspace.
