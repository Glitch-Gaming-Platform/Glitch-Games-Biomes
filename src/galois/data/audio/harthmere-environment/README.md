# Harthmere environment audio

- `cave-music-loop.webm` is the active 4:48 seamless cave-exploration music
  source used by the `cave_music` background track. It uses a darker,
  pulse-driven haunted-dungeon arrangement.
- `cave-music-loop-melancholy-v2.webm` is the preserved earlier 4:18 cave
  score with the gentler melancholy orchestral arrangement.
- `mountain-wind-loop.webm` is the active 26-second seamless summit ambience
  used when the player is outdoors on high snow or supported high-altitude
  terrain.
- `cavern-loop-with-wind.webm` is the preserved earlier 3:48 cavern music
  experiment with a passing-wind effect mixed into the music.
- `cavern-wind-pass.webm` is the preserved earlier standalone 9-second wind
  pass.

All files are preserved as game-ready 48 kHz Opus/WebM sources.

The MP3 copies, clean music masters, loop masters, generation prompts, and
composition plans remain under `artifacts/music/` in this workspace.
